# Impact Intelligence™ — Pitch Deck (One-Pager)

## Product Name
**Impact Intelligence** — A module for the VaultEd school intelligence platform.

## The Problem
Schools already test learners. Teachers already mark assessments. But after the marks are recorded, the learning evidence stays buried in mark books and spreadsheets. Teachers know some learners struggled, but they cannot quickly see which topics need re-teaching, which learners need support, or whether their class is improving over time.

## The Solution
Impact Intelligence turns teacher-marked assessments into **learning evidence**. It automatically calculates:

- **Weak topics** — Which areas of the curriculum need revision
- **Learner risk** — Which learners need additional support
- **Class support needs** — Which classes require attention
- **Intervention tracking** — Recommended actions for teachers
- **School-level impact reports** — Aggregated performance overview

Teachers enter marks once. Impact Intelligence does the rest — no spreadsheets, no manual calculations, no dashboards that require data analysts.

## Key Differentiators

| Feature | Impact Intelligence | Traditional Spreadsheets |
|---------|-------------------|------------------------|
| Weak topic detection | Automatic, rule-based | Manual calculation |
| Learner risk flags | Per-learner risk level | Absent |
| Intervention recommendations | Generated from data | Absent |
| School dashboard | Aggregated insights | Manual aggregation |
| Export & print reports | One-click CSV + PDF | Manual formatting |

## How It Works

1. **Teacher creates assessment** — Sets up subjects, topics, and questions
2. **Teacher enters marks** — Simple grid with keyboard-friendly entry
3. **Analytics engine runs** — Deterministic calculations (no AI required)
4. **Insights appear** — Weak topics, at-risk learners, interventions
5. **Reports generated** — CSV export, print-friendly PDF, school dashboard

## Value Propositions

### For Teachers
- **Time saved** — No manual pass rate calculations
- **Clear focus** — Know exactly which topics to re-teach
- **Learner support** — Identify at-risk learners early
- **Intervention ready** — Recommended actions for each weakness

### For School Heads
- **School intelligence** — See aggregated performance across classes
- **Support targeting** — Know which classes need help
- **Intervention priority** — Track recommended interventions
- **Report ready** — Export school impact reports for stakeholders

### For Education Stakeholders
- **Learning evidence** — Data-driven view of assessment outcomes
- **Aggregate overview** — Ministry-style demo dashboard
- **Privacy aware** — Learner codes only, no full names required

## Technology
- Fully deterministic analytics engine (no AI required to function)
- Optional AI summaries (advisory only — teacher always decides)
- Runs on school infrastructure or cloud
- Built on VaultEd — open-source, privacy-first education platform
