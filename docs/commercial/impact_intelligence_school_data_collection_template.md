| … | | | | | | | | |
| L030 | 2 | 3 | 4 | 1 | 3 | 2 | 3 | 1 |

### Mark Entry Tips

- Scores should be **out of the question's max marks** (shown in header row)
- Use decimals if needed (e.g. 7.5 / 10)
- Empty cell = not attempted (counts as 0)
- The system calculates total score and percentage automatically

## Data Checklist

Before submitting, confirm:

- [ ] School name is provided
- [ ] Class name is provided
- [ ] Subject name is provided
- [ ] All learner codes are unique (L001, L002, …)
- [ ] No learner names are included
- [ ] Topics are named
- [ ] Questions are numbered 1–N
- [ ] Each question has a max marks value
- [ ] Each question is linked to a topic
- [ ] Each learner has a score for each question (or blank)
- [ ] Total marks in assessment matches sum of question max marks

## Submission

Send the completed template to the Impact Intelligence team. Data will be entered into the system within 1 business day.
