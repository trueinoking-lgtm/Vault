# Impact Intelligence

**Turn teacher-marked tests into learning evidence.**

---

## The Problem

Schools test learners regularly — weekly tests, exams, diagnostics. But once the marks are recorded, they sit in a mark book. Teachers have no easy way to spot:

- Which topics the whole class is struggling with
- Which learners need extra support
- Which questions were too hard or too easy
- Whether interventions are actually working

A teacher with 30+ learners cannot see these patterns by hand.

---

## What Impact Intelligence Does

Impact Intelligence takes the marks teachers already collect and turns them into **clear, actionable reports**:

| You provide | We show |
|-------------|---------|
| Marks per learner per question | Which topics need re-teaching (sorted by weakest first) |
| Question-to-topic mapping | Which learners are at risk (scored, ranked, flagged) |
| Class and subject info | Which classes need support (pass rate, learners, trends) |
| Assessment pass mark | Intervention recommendations (critical, weak, stable) |
| Follow-up marks | Improvement comparison (before vs after) |

---

## Key Benefits

**For teachers** — Know exactly what to re-teach and who needs help, in minutes instead of hours.

**For heads of department** — Compare class performance, spot curriculum gaps, track intervention effectiveness.

**For school leadership** — School-wide impact reports with aggregate data, ready for staff meetings and stakeholders.

**For learners** — Targeted support based on actual performance data, not guesswork.

---

## How It Works

```
Teacher marks tests as usual
        ↓
Marks entered into Impact Intelligence
        ↓
Analytics engine calculates:
  • Topic performance (weakest → strongest)
  • Learner risk (high → low)
  • Question difficulty (hardest → easiest)
        ↓
Reports generated:
  • School dashboard (live)
  • Weak-topic report
  • Learner risk report
  • Intervention plan
  • Print-ready school report
        ↓
Teacher reviews findings and adjusts teaching
        ↓
Follow-up assessment shows improvement
```

---

## Privacy First

- **No AI decides learner performance** — all analytics are deterministic calculations from marks
- **No learner names required** — codes only (L001, L002)
- **No data shared outside the school**
- **No automatic marking** — teachers retain full control
